不需要。日本东京属于海外地域，域名解析到日本服务器不用走 ICP 备案流程，这也是很多人选海外节点的原因之一。

**支持支付宝付款吗？**

不太适合。按流量计费时日本节点流量单独结算，国际版按量模式还不能购买流量包，流量大的站开销涨得很快。这类业务更适合固定带宽包月，或者把下载、视频类流量放到别的方案上。
